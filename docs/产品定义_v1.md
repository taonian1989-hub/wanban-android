# 玩伴产品定义 v1

日期：2026-10-22。目标用户为单人使用的个人娱乐助手，覆盖影视、音乐、游戏、闲聊。无注册或登录门槛。

主任务是帮用户把一段闲暇变成一个可行动的小选择。竞争产品中的自然语言追问、可核查搜索、媒体收藏与轻互动作为能力参考；不复制品牌、页面或内容资源。

产品循环为「表达当下需求 → 给少量理由明确的选项 → 追问调整 → 保存期待 → 标记体验过」。首页以心情与时间作为轻量输入，持久输入框允许用户随时直接表达。AI通过结构化回答产生收藏卡，普通文本继续渲染。

四个主入口为此刻、聊聊、游乐场、收藏。设置收进右上角。手机以底部导航为主，大屏使用左侧导航；单屏只显示一种。暖白、橙色强调、植物绿媒体卡、原创几何插画、大留白；深色主题为森林底色。动效跟随减少动态效果设置，表单和图标按钮提供标签。

本版离线能力为十项精选娱乐条目、8题知识局、6组二选一、本地收藏与备份。智能能力为自带模型Key的聊天、推荐、互动故事和联网检索。片单是精选而非实时榜单，作品播放和购买留给用户选择的平台。

AI生成最多3条推荐的提示词，前端容忍最多6条有效卡片。没有有效结构时保留普通答案，用户不会因模型格式不合规而失去正文。思考展示默认关闭，当前所选服务商可启用；关闭展示不改变服务商自身的思考模式或计费。

可验证的完成条件：签名有效的APK、无登录启动、可离线收藏与游戏、四槽模型配置、搜索来源及失败状态、会话隔离与保存、备份预览和恢复、手机及大屏布局。真实Key和真机运行列为后续联调项目，不把浏览器模拟当作实网验证。
