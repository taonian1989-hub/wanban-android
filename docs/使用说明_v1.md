# 玩伴使用说明 v1

## 安装

安装 `玩伴_0.1.0_预览版.apk`，支持Android8.0及以上；建议先更新系统WebView。按系统提示允许当前文件管理器或浏览器安装应用。无需账号。

## 本地娱乐

在「此刻」点心情和空闲时间，推荐会随之调整。15/30分钟优先展示音乐；更长时间展示电影。点「换个灵感」循环查看精选。影视、音乐、游戏入口可筛选下方卡片；内容可滚动。作品详情说明推荐理由，点心形收藏。

「收藏」可搜索、切换类型、筛选想体验或体验过。点条目下方状态文字切换体验状态。右上角加号可以手工保存电影、音乐、游戏或自己的娱乐灵感。移除前会确认。

「游乐场」中的知识局和二选一离线可用。互动故事需要模型，文本生成后可回复选项继续故事。知识局共8道固定题，最高分保存在本机。

## 连接模型

右上角 → 偏好与连接 → 服务商。预设支持DeepSeek、Kimi、GLM，也可以填自定义Chat Completions兼容接口。

填写完整HTTPS对话地址、模型ID与API Key。Key来自各服务商开发者平台，消费端会员不等同于API额度。默认模型为deepseek-flash、kimi-k3、glm-5.3；如果账号无权限，可修改为自己可用的模型。自定义接口必须以 `/chat/completions` 结尾。

先保存，再点「测试已保存连接」。测试成功表示当时服务商返回了可展示正文。修改表单后未保存的值不会用于测试。Key不回显；留空保留原Key，更换地址后必须重新填写Key。

主输入框可以直接说「我有30分钟，想听点轻松的」或「不要恐怖片，换成喜剧」。AI作品卡片可直接收藏。普通聊天也可复制回答。回车换行，Ctrl/Command+Enter发送；手机点橙色箭头发送。语音可使用系统输入法。

生成时箭头变成停止按钮。停止保留已收到内容；错误、停止或空正文后，请点重新生成或新建对话。重新生成可能重新产生模型和搜索费用。右上角时钟查看历史，加号新建。切换服务商会新建会话；打开历史仍使用该会话原服务商。

## 联网搜索

先配置GLM的官方地址与有效Key，聊天模型可以使用任何已配置槽。点输入框下的「联网」开启，再发送消息。

本轮输入开头最多128个Unicode字符用作搜索词，尽量把具体作品、地区、日期放在前面，不要混入私密内容。搜索摘要随后发送给当前模型。来源编号显示在回复下方，点开后使用系统浏览器核查。

搜索失败会停止本轮并提示，不会装作检索成功。修改搜索词、检查GLM权限或关闭联网后重试。自定义代理配置中的Key不能用于官方搜索。应用不包含免费的公共搜索额度。

## 个性化与数据

兴趣方向影响本地排序。默认不向AI共享本机偏好；开启「给AI一点灵感」后，将心情、空闲时间、兴趣及前20条收藏标题、类型、状态附带到每次调用，不附带收藏备注。当前对话和设备日期是模型交互必要输入。

设置可选日间暖白、夜间森林或跟随系统。导出备份为明文JSON，含收藏、偏好、最高分与对话，不含Key。恢复先显示条数，确认后替换本机数据。请在恢复前导出当前备份。卸载或清除数据前也必须备份。

本机快照读取失败会暂停写入并提供原始加密文件导出，不自动当成空数据覆盖。加密原始文件需要原设备Key，不能充当跨设备的普通JSON备份。

浏览器预览仅用于查看界面，不能配置真实Key。没有内置影音播放、云同步、实时榜单或自动下载。AI可能给出不准确建议，片源、价格、发行信息、评分等请自行核查。
