# 玩伴 0.2.0 个人预览版

玩伴是免登录的安卓个人娱乐助手，提供影视、音乐、游戏发现、轻松聊天与本机小游戏。支持Android8.0及以上，建议更新系统WebView。

## 本版内容

- 新增五子棋与中国象棋，支持离线人机练习、双人同屏、悔棋、重新开局和胜负判定。
- 象棋提供合法落点提示，检查蹩马腿、塞象眼、将帅照面、应将、将死与困毙；采用应用内明确说明的休闲和棋约定。
- 保留心情与时间精选、统一收藏、知识局、二选一和AI互动故事。
- 支持DeepSeek、Kimi、GLM及自定义Chat Completions接口；独立GLM联网搜索可搭配任意聊天模型，回复显示来源。
- 本机加密保存模型Key与个人数据，支持JSON备份与恢复，提供深色主题与大屏布局。

## 下载与升级

下载Assets中的 `wanban-0.2.0-preview.apk`，传到安卓手机安装。无需账号；本地精选、收藏和棋类游戏无需模型Key。

AI聊天使用你自己的API Key，联网搜索需要GLM官方接口配置及额度。第三方模型与搜索由服务商计费，应用不提供Key或额度，也不内置影视或音乐播放。

本版与先前本地分发的0.1.0使用相同包名和签名，版本代码从1升至2，可覆盖升级；升级前可先导出备份，不需要卸载。源码附件不包含签名私钥，开发者自行构建会使用自己的签名。

## 验证范围

0.2.0完成186项本地断言，涵盖44项棋类规则、37项棋盘界面及原有核心、通用UI和模拟AI交互回归。APK的v2/v3签名有效，并核对同签名升级条件。界面截图来自相同资源的浏览器预览。

本版为个人预览版，尚未完成真实模型Key与Android真机联调。棋类电脑为本机入门算法；棋局在本次运行内保留，重启应用后重新开局；象棋不裁定比赛规则中的长将长捉责任。

附带完整源码、可交互HTML预览、使用说明、验收记录、棋盘截图及SHA256校验文件。HTML预览用于体验界面，禁用真实Key配置。

Release附件采用英文文件名以确保跨平台下载与校验一致；本机构建脚本仍生成中文文件名。
