# 接口依据 v1

2026-10-22核对官方文档。预设ID可编辑，不代表保证账号可调用。

| 服务 | 对话地址 | 预设模型 | 官方文档 |
| --- | --- | --- | --- |
| DeepSeek | https://api.deepseek.com/chat/completions | deepseek-flash | [首次调用](https://api-docs.deepseek.com/) |
| Kimi | https://api.moonshot.cn/v1/chat/completions | kimi-k3 | [Chat Completions](https://platform.kimi.com/docs/api/chat) |
| GLM | https://open.bigmodel.cn/api/paas/v4/chat/completions | glm-5.3 | [对话补全](https://docs.bigmodel.cn/api-reference/模型-api/对话补全) |

统一Chat Completions流式SSE，兼容非流式JSON。Kimi K3使用max_completion_tokens；其他默认max_tokens。对预设DeepSeek和GLM相应模型按已有官方协议开启thinking，并使用low推理强度；思考显示开关只控制界面，不改变计费。自定义接口不假定服务商推理参数。支持协议有限，未适配Responses或Anthropic接口。

搜索使用独立 [GLM Web Search](https://docs.bigmodel.cn/api-reference/工具-api/网络搜索)，POST `https://open.bigmodel.cn/api/paas/v4/web_search`。字段为search_query、search_engine=search_std、count=8、content_size=high，读取search_result的title/link/content/media/publish_date。摘要大小参数依据 [官方概览示例](https://docs.bigmodel.cn/cn/guide/tools/web-search)。去重、过滤非HTTP(S)和带用户密码的URL，最大8条、每条6000摘要字符。

携带凭证的请求不跟随重定向、不自动重试；搜索必须配置为GLM官方地址。检索摘要视为不可信证据，不改变应用系统提示，不直接成为可执行操作。外部来源在系统浏览器打开。

界面设计采用自己的暖白橙色与几何插画，参考 [Google表达性设计研究](https://developer.android.com/design/ui/wear/guides/get-started/benefits?hl=en) 中对功能清晰、视觉层级和可访问性的原则，非官方Material组件实现。
