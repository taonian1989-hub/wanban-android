# 棋类游戏说明 v2

2026-10-23，玩伴0.2.0新增五子棋与中国象棋。入口为底部「游乐场」。两款均完全离线，不需要登录、网络或模型Key。

## 共同操作

默认「人机练习」，你执先手，玩伴使用本机入门算法回应；「双人同屏」可在同一手机轮流下棋。棋盘上方显示行棋方和步数。重新开局和在已有棋局中切换模式需要确认。

「悔棋」在人机练习中撤回你与电脑的一轮，在双人同屏中撤回一步。电脑尚未回应时可立即悔棋，已排队的回应会取消。游戏结束后也可以悔棋复盘。

离开游戏页后，本次棋局在当前应用运行期间保留；重新打开继续。应用重启后从初始局面开始；棋局不进入个人数据备份。使用物理键盘时可用方向键选择交叉点，Enter或空格确认。

## 五子棋

15×15棋盘，黑先白后。点击交叉点落子，橙点标记最后一手。横、竖或斜向连续五子或以上获胜，获胜连线会标出。满盘无人获胜则和棋。

采用自由规则，不设三三、四四、长连禁手或交换开局。人机练习中你执黑，电脑执白；算法优先完成五连或阻挡对方的直接胜着，适合轻松练习。

## 中国象棋

红先黑后。先点自己的棋子，合法落点会亮起，再点击目标落子或吃子。点另一枚己方棋子可重新选择，再点已选棋子取消选择。人机练习中你执红，电脑执黑。

实现车、马、象相、士仕、将帅、炮与兵卒走法，包括蹩马腿、塞象眼、象不过河、将士不出九宫、炮架、过河兵卒横行，以及将帅不能照面。不能送将，被将军时必须解除威胁；将死或无合法着法（困毙）判负。

休闲和棋约定：同一局面连同行棋方出现三次，或连续120个单方步无吃子且无兵卒移动，判和。本版不裁定比赛规则中的长将、长捉责任；不提供竞赛级引擎或远程联机。

规则依据为 [世界象棋联合会2018规则](https://www.wxf-xiangqi.org/images/wxf-rules/2018_World_XiangQi_Rules_English2018.pdf) 的基本走法与终局规则；重复局面处理为本应用明确说明的休闲约定。没有使用或打包第三方象棋引擎。
